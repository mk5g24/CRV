# CRV

A MATLAB helper object that allows efficient sparse matrix storage, scalar multiplication, matrix-matrix addition, multiplication and Kronecker prdocuts using the COO format and internal MATLAB functions. Based on functions https://uk.mathworks.com/matlabcentral/fileexchange/20820-the-matrix-function-toolbox and https://uk.mathworks.com/matlabcentral/fileexchange/181316-csr-sparse-matrix.
